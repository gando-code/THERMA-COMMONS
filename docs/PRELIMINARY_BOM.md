# Preliminary bill of materials

Functional procurement list for one bench demonstrator. No supplier, part number, material or compliance claim is prequalified. Category cost ceilings come from the feasibility budget and include supporting work; they are not a sum of vendor quotes.

| Item | Initial quantity | Selection evidence required |
|---|---:|---|
| Removable vessel and lid | 1 plus spare | Contact compatibility, fill limits, cleaning access |
| Controlled contact heater | 1 | Power rating, thermal contact, independent limit |
| Sealed cooling assembly | 1 | Rated operating envelope, refrigerant, useful cooling capacity |
| Secondary-loop exchanger and pump | 1 set | Pressure, temperature and fluid compatibility |
| Insulated tubing and fittings | 1 set | Leak resistance, condensation control |
| Removable guarded stirrer | 1 | Load suitability, stall behavior, cleaning |
| Control temperature channel | 1 | Range, response, calibration path |
| Independent reference channels | 3 | Separate logger, calibration and uncertainty |
| Independent reference logger | 1 | Synchronized records at 1 Hz or faster |
| Scale and wall-energy meter | 1 each | Range, resolution and documented check |
| Controller and status interface | 1 | Offline operation and deterministic state reporting |
| Independent thermal limiter | 1 set | Fault-independent cutoff and reset behavior |
| Reviewed power and protection assembly | 1 set | Electrical ratings, isolation, qualified review |
| Enclosure, drip containment and drainage | 1 set | Wet-zone separation and inspectability |
| Cleaning and measurement consumables | 1 set | Repeatable protocol and traceability |

Obtain quotations after architecture review. Record manufacturer, model, revision, supplier, date, price, lead time, rating evidence, substitution rules and approval. Treat donated components with the same acceptance criteria as purchased ones. Procurement alone does not establish device compliance.
