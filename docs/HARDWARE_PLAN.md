# Hardware development plan

## Phase one

Select one removable vessel, qualified heating element, reviewed refrigeration module and independently logged reference sensors. Assign responsible thermal, electrical and measurement reviewers. Define the wet zone, drainage, load support and service access before procurement. The current source code is an algorithmic reference only and must not be connected to hardware without a separate implementation and hazard review.

Required pre-build records: approved requirements, schematics, wiring ratings, food-contact material declarations, coolant compatibility, refrigerant information, protective-device selection, assembly inspection and test-site authorization. Choose a cooling system on useful heat extraction and total electrical input, not advertised input wattage alone.

## RF and advanced branches

RF heating requires a separate specialist cavity, interlock, field-distribution, arcing, leakage and EMC program. Do not modify consumer microwave interlocks. A contact-heating vessel may be unsuitable for an RF cavity. Vacuum cooling requires pressure-rated engineering and food-specific moisture/texture studies. Electrocaloric and magnetocaloric ideas remain research options, not product dependencies.

## Required artifacts before powered testing

Reviewed drawings and wiring; component ratings; safe operating procedure; emergency isolation; training; fault matrix; measurement uncertainty budget; commissioning checklist and incident process. No production PCB layout, Gerber, manufacturing CAD, certified BOM or qualified embedded firmware is claimed in this repository. Those require actual design choices and physical verification.
